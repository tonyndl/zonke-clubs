## Image Requirements

- **Format**: JPG, PNG, or WebP
- **Size**: Recommended 1200x800px or similar aspect ratio
- **Quality**: High-quality promotional photos of the nightclubs
- **Content**: Exterior or interior shots showing the club's atmosphere

## Finding Images

You can:

1. Search for official club photos from their social media (Instagram, Facebook)
2. Use stock photos of nightclub interiors/exteriors
3. Use placeholder images from services like Unsplash or Pexels

## Adding Images

1. Download or create the image files
2. Rename them according to the filenames above
3. Place them in this directory (`backend/priv/clubs/`)
4. Run the seed script: `mix run priv/repo/seeds.exs`

## Placeholder Images

For development/testing, you can use generic nightclub images as placeholders until you have the actual club photos.
